Cloud-Sicherung (GitHub)

Speichert alle Blätter als JSON in einem eigenen Repository.

Empfehlung: ein privates Repo nur für die Daten, z. B. arbeitsblatt-daten. Token: Fine-grained, nur dieses Repo, Berechtigung Contents: Read and write. Der Token bleibt im Browser und wird nur an api.github.com gesendet.

LaTeX übernehmen

Code einfügen oder eine .tex-Datei wählen – daraus werden bearbeitbare Bausteine.

Erkannt werden Absätze, \\section, Aufzählungen (itemize/enumerate), Formeln ($…$, \\[…\\]), tcolorbox und die übliche Textformatierung. Danach alles normal weiterbearbeiten.

Neues Arbeitsblatt

Layout wählen – lässt sich später jederzeit ändern.

Arbeitsblatt mit KI

Links einstellen, Prompt kopieren, Antwort rechts einsetzen – ohne API-Key.

Bausteine
